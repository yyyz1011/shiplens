# Acceptance sensitivity case study

Run `npm run benchmark:audit` after `npm ci` and `npm run browsers`. Output is local under `artifacts/check-audit-*`. Set `SHIPLENS_RECORD_CHECK_AUDIT=1` only to replace the public fixture evidence and results intentionally; format `apps/docs/public/check-audit/results.json` afterward. `npm run benchmark:verify` checks the committed case study and artifact digests.

Three maintainer-authored requirements specify order total, inventory and delivery days. Each has a known incorrect text fixed before execution. There is one repetition with desktop/mobile observations. The independent Playwright baseline reads visible element text and applies its own whitespace normalization, `includes` and equality predicates. These predicates intentionally match the configured weak and strong ShipLens checks; this is not a comparison against an unconfigured framework or a model.

The runner first reads both website states with Playwright. It collects four ShipLens runs: weak/strong rules on specified content, and weak/strong rules on the known wrong content. The fixture server is then stopped. The new audit checks synthetic variations against saved text, including each predeclared wrong value. It must report the same sensitivity as the independently exercised wrong browser states. Artifacts comprise 24 component PNGs and 24 corresponding observations, listed with SHA-256 digests in the result. Digests identify these controlled artifacts; they are not authenticity signatures.

The result demonstrates a packaged way to expose insensitive text assertions using already-collected evidence. All six wrong viewport observations pass weak predicates in both implementations; all six fail expected-value predicates. The offline audit exposes the same six custom counterexamples. It cannot establish superior browser detection, rendered mutation execution, source-level mutation coverage, AI reasoning, speed, tokens, human effort, customer benefit or demand. A custom script can reproduce the string simulation. Automatic numeric changes may be irrelevant to an actual requirement, so survivors are advisory; no coverage score or automatic acceptance failure is inferred.
